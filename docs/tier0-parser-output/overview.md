# Tier 0 parser output reference

This folder is a **read-only reference**, not a test suite. It shows the
actual `EvidenceRecord` (node) and `EdgeRecord` (edge) objects each Tier 0
extractor produces for its fixture inputs, so a reader can see the real
shape of the data without running anything.

It does not replace or duplicate the test suite under `tests/` — those
files are untouched. This is purely documentation: source fixture in, JSON
out, side by side.

Generated by parsing each fixture with the parser's public entry point and
serializing the returned `(nodes, edges)` tuple via `dataclasses.asdict`.
`EvidenceRecord` / `EdgeRecord` are defined in
[`src/rudhmap/extract/schema.py`](../../src/rudhmap/extract/schema.py).

## Notes on reading the output

- `tier` is always `0` and `confidence` is always `1.0` for every record
  produced by these three extractors — Tier 0 treats declarative IaC as
  authoritative ground truth, never inferred.
- `file` paths are recorded exactly as returned by the parser on the
  machine that generated this doc (Windows-style backslashes). The
  identity/line/kind values are what matter, not the path separator style.
- `line` anchors at the resource/service/manifest-name declaration, not at
  the start of the block — see each parser's `_find_*_line` helper.
